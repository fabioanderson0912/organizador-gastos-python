# 💰 Organizador de Gastos

Sistema simples desenvolvido em Python para registrar e consultar
transações financeiras.

## 🚀 Funcionalidades

- Adicionar transações
- Visualizar saldo
- Consultar extrato
- Separar receitas e despesas
- Menu interativo

## 🛠️ Tecnologias

- Python
- Estruturas condicionais
- Loops
- Funções
- Listas
- Manipulação de dados

## ▶️ Como executar

```bash
python main.py
